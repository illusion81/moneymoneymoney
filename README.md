# moneymoneymoney

A Flutter app.

## Setup

Requires the [Flutter SDK](https://docs.flutter.dev/get-started/install) (developed against Flutter 3.41, Dart SDK `^3.11.0`).

```sh
flutter pub get      # install dependencies
flutter devices      # list available targets
flutter run          # run the app (add -d <device> to pick a target)
```

## Common commands

```sh
flutter test         # run tests
flutter analyze      # static analysis / lints
flutter build apk    # release build (also: ios, macos, linux, windows, web)
```
